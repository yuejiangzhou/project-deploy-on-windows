# 研发任务拆解 — 内部产品打包分发系统

> 基于 PRD v1.1 + 评审结论  
> 总工作量: ~44 人天，建议 2 人并行 1 个月

---

## 开发顺序（按依赖关系）

```
Phase 1: 基础设施（无依赖，可并行）
├── T1.1 数据库迁移
├── T1.2 Spring Security + JWT
├── T1.3 前端路由守卫 + Pinia + MainLayout
└── T1.4 前端 Login 页面

Phase 2: 核心功能（依赖 Phase 1）
├── T2.1 License 后端模块（CRUD + 生成 + MinIO存储）
├── T2.2 License 前端页面
├── T2.3 Redis 全链路支持（后端）
└── T2.4 打包引擎改造（License注入 + Redis + 脚本模板）

Phase 3: 页面改造（依赖 Phase 1-2）
├── T3.1 现有4页面改造（权限适配 + Redis + 字段对齐）
├── T3.2 UserManagement 页面
└── T3.3 联调测试

Phase 4: 打包验证
└── T4.1 Windows 全流程测试 + MySQL安全版 + Redis兼容性
```

## Phase 2: 核心功能（Week 3-4）

### T2.1 License 后端模块
- [ ] 创建 LicenseRecord Entity + Mapper
- [ ] 实现 LicenseService（generate/renew/list/download）
- [ ] 实现 LicenseController（REST API）
- [ ] License 生成逻辑：RSA-2048 SHA256withRSA 签名 JSON data
- [ ] License 文件格式：`{"data": "{...}", "signature": "base64..."}`
- [ ] Runtime timestamp 生成：AES-ECB 加密当前时间戳
- [ ] 存储到 MinIO：licenses/{id}/license.lic + licenses/{id}/timestamp.dat
- [ ] 创建 api/license.js（前端 API 封装）
- [ ] 创建 stores/license.js（License 列表缓存）

### T2.2 License 前端页面
- [ ] 创建 views/LicenseManagement.vue（搜索 + 表格 + 生成/续期弹窗）
- [ ] 生成 License 弹窗：选择项目 + 客户名称 + 试用天数 + 类型(TRIAL/PERMANENT)
- [ ] 续期弹窗：新试用天数
- [ ] 表格列：客户名称 | 项目 | 类型 | 过期时间 | 状态 | 操作人 | 操作(下载/续期/吊销)
- [ ] License 状态标签：ACTIVE=绿, EXPIRED=红, REVOKED=灰

### T2.3 Redis 全链路支持
- [ ] FileTypeEnum 增加 REDIS

- [ ] Project Entity 增加 redisComponentId, redisPort, includeRedis
- [ ] 数据库迁移脚本增加对应字段
- [ ] ProjectService 保存配置时处理 Redis 字段
- [ ] ProjectConfigDTO 增加 Redis 字段

### T2.4 打包引擎改造
- [ ] PackageStartRequest 增加 licenseId 字段
- [ ] PackageService.startPackage() 增加 licenseId 参数
- [ ] executePackageAsync() 插入 License 注入步骤（在生成脚本之后、打包之前）
- [ ] 实现 injectLicense() 方法：下载 .lic 和 timestamp.dat 到对应目录
- [ ] 增加 Redis 收集步骤（collectRedis）
- [ ] 增加 Redis 启动/停止脚本模板
- [ ] 脚本模板从 .ps1 改为 .bat + .ps1 混合方案
