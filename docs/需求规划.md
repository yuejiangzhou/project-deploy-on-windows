## 一、核心决策记录

| 决策项 | 结论 | 确认方式 |
|--------|------|---------|
| 打包产物形态 | 全量便携包，Windows 解压即用 | 用户选择 |
| 系统形态 | Web 管理��统（SpringBoot + Vue） | 用户选择 |
| License 机制 | 离线 License 文件，Web 端生成+续期，客户手动替换 | 用户选择 |
| 基础服务方案 | Windows 便携版（MySQL/Redis/MinIO/Nginx/自研引擎） | 用户选择 |
| 版本管理 | 组件级版本（前端/后端/基础服务独立版本，打包时组合） | 用户选择 |
| 打包执行位置 | 服务端打包 | 用户选择 |
| 文件存储 | MinIO | 用户明确 |
| MySQL 安全 | 禁用 skip-grant-tables，分纯净版和已初始化版 | 用户明确 |
| JDK | 当前 JDK8，架构预留多版本扩展 | 用户明确 |
| 打包系统部署 | 待确认 | 用户暂未确定 |
| 客户环境 | Windows，内网 | 用户明确 |
| 额外基础服务 | 自研后端引擎 | 用户明确 |
| License 代码 | 已有现成代码，开发时提供 | 用户明确 |
