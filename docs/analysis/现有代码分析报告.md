## 二、数据库差距

现有 4 张表：project、uploaded_file、package_record、package_task

需要新增：
- **license** 表 — License 文件管理
- **license_record** 表 — License 生成/续期记录
- **user** 表 — 用户和角色管理

需要改造：
- **uploaded_file** 表 — 补充 version/version_label/init_state/belong_system 字段
- **project** 表 — 补充组件选择外键、账密字段
- 新增 **组件版本库**概念

---

## 三、架构可复用性

现有后端架构（SpringBoot + MyBatis-Plus + MinIO + FreeMarker）完全可以直接改造使用。主要改动点：

1. **新增 License 模块**：独立的 Controller/Service/Entity
2. **改造打包引擎**：注入 License 文件到产物
3. **新增用户/角色模块**：区分开发/销售权限
4. **改造启动脚本模板**：加入 License 校验逻辑
5. **增强组件管理**：版本库、兼容性矩阵
